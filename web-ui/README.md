# وب اپلیکیشن شمارش‌گر افراد (نسخه وب)

رابط وب فارسی و راست‌به‌چپ برای موتور شمارش افراد — جایگزین وبی رابط دسکتاپ PyQt6،
ساخته‌شده با React + Vite + Tailwind v4 و سیستم طراحی «گرافیت» از رجیستری VibeFarsi.

> این نسخه‌ی دوم است؛ نسخه‌ی اول در پوشه‌ی `../frontend` قرار دارد و هر دو به همان
> API سریع (`app/server.py`) وصل می‌شوند.

## تفاوت‌ها با نسخه اول

* تم تیره‌ی «گرافیت»: پس‌زمینه‌ی سیاه خنثی، خطوط مویی ۱ پیکسلی، دکمه‌ی سفید و تأکید کهربایی — مناسب اتاق مانیتورینگ.
* بدون وابستگی به کتابخانه‌ی UI: همه‌ی کامپوننت‌ها (دکمه، ورودی، کارت، دیالوگ، جدول، نمودار، تقویم) کپی‌شده از رجیستری VibeFarsi و در پروژه نگه‌داری می‌شوند.
* نمودارهای SVG خالص راست‌به‌چپ با محور مقدار در سمت راست و برچسب‌های شمسی.
* تقویم شمسی کامل (شنبه‌شروع، جمعه‌های خاکستری) در فیلترهای گزارش.
* اعداد فارسی ۰–۹ با جداکننده‌ی «٬» در کل رابط؛ داده‌ی خام (IP، آدرس RTSP) با `dir="ltr"` چپ‌چین می‌ماند.
* آیکون‌ها فقط از lucide-react؛ چورون «بعدی» در RTL به چپ اشاره می‌کند.

## صفحات

| مسیر | توضیح |
| ---- | ---- |
| `/login` | ورود با نام کاربری/رمز (JWT + refresh خودکار) |
| `/` | داشبورد: کارت‌های KPI، کاشی‌های ویدیوی زنده MJPEG، شمارش زنده هر دوربین |
| `/cameras` | فهرست، جستجو، افزودن/ویرایش (سه حالت RTSP دستی، آدرس کامل، فایل)، آزمایش اتصال، فعال/غیرفعال، حذف |
| `/zones` | ویرایشگر گرافیکی خط و منطقه روی اسنپ‌شات دوربین (کشیدن، جابه‌جایی دسته‌ها، جهت خط) |
| `/reports` | فیلتر تاریخ شمسی و دوربین، تجمیع ساعتی/روزانه/هفتگی/ماهانه، نمودار روند، ساعات پرترافیک، خروجی CSV/اکسل/PDF |
| `/users` | مدیریت کاربران و نقش‌ها + گزارش رخداد (فقط مدیر) |
| `/settings` | وضعیت سرور و موتور تشخیص، تغییر رمز عبور |

## اجرا

```bash
# 1) بک‌اند
python -m app.server --host 0.0.0.0 --port 8000

# 2) این رابط
cd web-ui
npm install
npm run dev        # http://localhost:3100
```

سرور توسعه‌ی Vite درخواست‌های `/api` و `/health` را به `127.0.0.1:8000` پروکسی می‌کند.
برای تغییر مقصد، `vite.config.ts` یا متغیر `VITE_API_URL` را ویرایش کنید.

ساخت نسخه‌ی نهایی:

```bash
npm run build      # خروجی در dist/
```

## ساختار

```
web-ui/
  src/
    api/            کلاینت axios (ات، توکن، refresh) + تایپ‌های اسکیمای بک‌اند
    lib/            utils (اعداد فارسی)، jalali (تقویم)، float (پاپ‌آور)
    components/
      ui/           دکمه، ورودی، کارت، نشان، دیالوگ، هشدار، نمودار، تقویم، انتخاب تاریخ، ...
      AppShell.tsx  نوار کنار RTL + نوار بالا + تب‌بار موبایل
      ZoneCanvas.tsx  بوم ویرایش خط/منطقه
    pages/          هفت صفحه‌ی برنامه
    index.css       تم گرافیت + نگاشت توکن‌ها به Tailwind v4
```
